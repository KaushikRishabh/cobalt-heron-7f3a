# Wind Decision Desk

A React and TypeScript interface with a Python FastAPI backend for exploring historical wind forecasts and observed generation. The app includes a reproducible snapshot of public Elexon data and does not need API credentials.

## Run locally

Use Python 3.12 and Node.js 24.

```sh
python3 -m venv backend/.venv
source backend/.venv/bin/activate
pip install -r requirements.txt
npm --prefix frontend ci
npm --prefix frontend run build
python -m uvicorn app:app --host 127.0.0.1 --port 8000
```

Open http://localhost:8000. API documentation is at http://localhost:8000/docs.

The project also includes a Dockerfile and Compose configuration:

```sh
docker compose up --build
```

Container build and runtime have not yet been verified in this workflow. No public app deployment has been completed.

## Architecture

| Path | Purpose |
| --- | --- |
| `frontend/` | React and TypeScript views, controls, charts and CSV exports |
| `backend/analysis.py` | Forecast selection, alignment and calculations |
| `backend/store.py` | Snapshot validation and caching |
| `backend/main.py` | Typed API endpoints and input validation |
| `backend/tests/` | Backend tests |
| `data/` | Bundled public Elexon records and provenance |
| `scripts/fetch_data.py` | Explicit data refresh script |
| `app.py` | API and compiled frontend on one origin |
| `Dockerfile`, `compose.yaml` | Container build and local startup configuration |
| `vercel.json` | Prepared deployment configuration, not a verified deployment |
| `.github/workflows/checks.yml` | Automated tests, build and container smoke checks |

## Public data

Data comes from Elexon's public WINDFOR and FUELHH endpoints. Retrieval information and checksums are included in the snapshot and exposed by `/api/metadata`. Elexon does not endorse this project.

- [WINDFOR documentation](https://bmrs.elexon.co.uk/api-documentation/endpoint/datasets/WINDFOR/stream)
- [FUELHH documentation](https://bmrs.elexon.co.uk/api-documentation/endpoint/datasets/FUELHH/stream)
